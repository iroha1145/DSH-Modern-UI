# 2026-10-26 手机滑动与复审后续修复

本轮在 `43cda67` 的基础上修复一个手机上的问题，并处理合并后再次审查找到的几处缺陷。没有改会话格式，也没有迁移用户数据。

## 手机上整页被拖动

在手机上打开插件、自动化任务、上下文洞察等页面，内容滑到顶或底以后继续拖动，整个页面会连同顶栏一起被拖动；安卓上还会触发下拉刷新。对话页面平时停在底部，较少遇到。

原因是越界的拖动会一路传到页面根部。应用的每个滚动区域都在框架内部，文档本身从不滚动，所以给 `html` 和 `body` 加上 `overscroll-behavior-y: none`，越界拖动就停在页面自己的滚动区域里。各页面内部滚动和回弹不受影响。

## 再次审查后的修复

| 问题 | 修复 |
| --- | --- |
| 模型选择器里「思考」「联网」两个开关在保存期间被原生禁用。用键盘操作时，焦点会跳回菜单开头；WebKit 上失焦还可能关掉整个选择器。 | `Switch` 新增忙碌状态：保存期间外观和读屏提示与禁用相同（`aria-disabled`），点击被忽略，但开关仍可获得焦点。两个开关改用忙碌状态，和推理档位按钮的做法一致。 |
| 命令目录每次后台刷新都先清空，选择器打开时联网开关会消失再出现，焦点在开关上时会掉到页面主体。 | 已就绪的目录在后台刷新期间继续显示原内容；刷新失败、会话组合变化或首次加载时照旧隐藏。 |
| 安装路径的某一级上级目录可以进入但不能列出内容（例如 0711 的家目录或挂载点）时，POSIX 安装器报「无法确认目录的真实位置」并退出。 | 上级目录不可读时，沿用 `pwd -P` 给出的名字，并确认它和真实目录是同一个；报错信息写明可能是权限原因。新增夹具在修复前失败、修复后通过。 |
| PowerShell 安装器枚举安装目录和数据目录时把方括号当作通配符，目录名带方括号时首次使用的数据备份会被静默跳过。 | 这两处改为按字面路径处理（`-LiteralPath`）。本机没有 PowerShell，以 Windows 持续集成结果为准。 |

## 已知但本轮未处理

- PowerShell 在交互窗口中先切换目录、再用相对路径传 `-Dir` 或 `-DshHome` 时，路径按进程目录而不是当前位置解析。推荐的 `powershell -File` 运行方式不受影响。
- 在 PowerShell 集成脚本环境（ISE）中运行时，运行环境校验会用错宿主程序，安装无法完成。
- 切换私有 Node 后，旧版本留在 `runtime/node.previous`，多占一份磁盘空间，不影响功能。

前两项需要在 Windows 上实测，第三项不影响功能，都留到后续处理。

- 在手机尺寸（375 像素宽，触摸模拟）的 Chromium 中检查：文档没有可滚动的多余高度，`html` 与 `body` 的纵向越界设置为 `none`。真实的 iOS 回弹和安卓下拉刷新没有在实机上复现，依据是浏览器对 `overscroll-behavior` 的标准行为。
- 完整构建、宿主与客户端类型检查、全部客户端单元测试，以及依赖、导出文档和多语言等检查。
- 发行仓库的摘要检查与 POSIX 安装器夹具；Windows 部分以持续集成为准。
